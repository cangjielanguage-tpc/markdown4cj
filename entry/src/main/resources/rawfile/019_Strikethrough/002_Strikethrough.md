### 严格宽松界定符的删除线用例

~~《2026年校园膳食经费管理专项检查表》~~

~~ 《2026年校园膳食经费管理专项检查表》 ~~

你好！您提供的这份文件是一份~~《2026年校园膳食经费管理专项检查表》~~。

你好！您提供的这份文件是一份~~ 《2026年校园膳食经费管理专项检查表》 ~~。

~~《2026年校园膳食经费管理专项检查表》~~哈哈哈。

~~ 《2026年校园膳食经费管理专项检查表》 ~~哈哈哈。

前缀~~加粗内容~~后缀

前缀 ~~加粗内容~~ 后缀

中文前缀~~安全、规范、透明地使用~~中文后缀

~~安全、规范、透明地使用~~，后面继续普通文本。

多个加粗：~~第一个~~，普通文本，~~第二个~~。

加粗里有标点：~~《检查表》：安全、规范、透明。~~

不完整语法：~~这里没有结束

行内代码不应加粗：`~~这里应该保留星号~~`

代码块不应加粗：

```js
const text = "~~这里应该保留星号~~"
```
