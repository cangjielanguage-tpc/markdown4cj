## 验证要点

1. 初始进入页面，第一张表第一条链接若在屏内应报 `visible:true`
2. 第二张宽表，右侧「参考链接」列初始在容器外，应不报；横滚进入后报 `visible:true`
3. 打开表格吸顶开关后，标题行吸顶，cell 位置随外层滚动变化，曝光仍应正确
4. 滚出（垂直或横向）应报 `visible:false`，与显示成对
