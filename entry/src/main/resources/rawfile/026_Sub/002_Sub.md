# Markdown 上下标测试文件（最终版）
## 规则：仅支持 **单层** 上下标，**不支持任何嵌套**

---

# 一、合法数据（正常渲染）
## 1. 原生 Markdown 单层
- 上标：`X^2^` → X^2^
- 下标：`H~2~O` → H~2~O

## 2. HTML 单层
- 上标：`<sup>2</sup>` → X<sup>2</sup>
- 下标：`<sub>2</sub>` → H<sub>2</sub>O

## 3. 合法内容类型（数字、字母、中文、符号）
- 数字：X^3^、H~2~O
- 字母：a^n^、C~o~
- 中文：注^上角^、底~下标~
- 符号：a^+−×÷^、A~!@#$~

## 4. 合法数据在各种块结构中
### 标题
# 标题 X^2^ H~2~O
## 标题 A<sup>2</sup> B<sub>2</sub>

### 段落
普通段落：X^2^、H~2~O、A<sup>2</sup>、B<sub>2</sub>

### 加粗 / 斜体 / 删除线
**X^2^**
*H~2~O*
~~X^2^~~

### 无序列表
- X^2^
- H~2~O

### 有序列表
1. X^2^
2. H~2~O

### 块引用
> X^2^
> H~2~O

### 表格
| 类型 | 公式 |
|------|------|
| 上标 | X^2^ |
| 下标 | H~2~O |

### 行内代码旁
函数`test()`：X^2^、H~2~O

### 代码块
~~~
X^2^
H~2~O
~~~

### 超链接
[链接 X^2^](https://example.com)

### 任务列表
- [x] X^2^
- [ ] H~2~O

### 脚注
内容[^1]
[^1]: 脚注：X^2^、H~2~O

### 版本标注

v2.1<sup>beta</sup>

v2.1^beta^

v2.1~beta~

v2.1<sub>beta</sub>

### 商标符号

Markdown<sup>®</sup>

Markdown^®^

Markdown~®~

Markdown<sub>®</sub>

# 二、异常数据（全部嵌套，均不支持）
## 1. HTML 嵌套异常（≥1层嵌套，全部非法）
- A<sup>a<sup>b</sup></sup>
- B<sub>a<sub>b</sub></sub>
- C<sup>a<sub>b</sub></sup>
- D<sub>a<sup>b</sup></sub>

## 2. 原生 Markdown 嵌套异常（非法）
- X^a^b^^
- Y~a~b~~
- X^a~b~^
- Y~a^b^~

## 3. 混合嵌套异常（非法）
- A<sup>x~y~</sup>
- B<sub>x^y^</sub>

## 4. 多层嵌套异常（非法）
- A<sup>1<sup>2<sup>3</sup></sup></sup>
- B<sub>1<sub>2<sub>3</sub></sub></sub>

## 5. 块结构内的异常嵌套
### 段落
A<sup>a<sup>b</sup></sup>、X^a^b^^

### 列表
- A<sup>a<sup>b</sup></sup>
- Y~a~b~~

### 表格
| 类型 | 异常嵌套 |
|------|----------|
| 上标嵌套 | A<sup>a<sup>b</sup></sup> |
| 下标嵌套 | Y~a~b~~ |

### 引用
> A<sup>a<sup>b</sup></sup>
>> Y~a~b~~

### 加粗/斜体异常
**A<sup>a<sup>b</sup></sup>**
*Y~a~b~~*
